# KWin Action Center (`kwin-action-center`)

A modern system tray and action center replacement for KDE Plasma 6, inspired by the clean and unified control center experience of Windows 11.

---

## Features
* **Modern Windows 11 Style UI:** Clean, sleek, and intuitive panel for quick system controls.
* **Comprehensive Controls:** Seamlessly manage Wi-Fi, Bluetooth, volume, brightness, and media playback.
* **Optimized Performance:** Built specifically for KDE Plasma 6 using QML and declarative applet scripting.
* **Built-in ScrollView:** Efficiently handles multiple networks and devices without layout breaking.

## Installation

### From KDE Store (Recommended)
1. Right-click on your Plasma panel or desktop and select **Add Widgets**.
2. Click **Get New Widgets** -> **Download New Plasma Widgets**.
3. Search for **KWin Action Center** and click **Install**.
